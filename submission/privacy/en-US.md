# Privacy Statement for Parallax Pilot

Parallax Pilot processes only the minimum device data required to run the game on the watch.

Data and device capabilities used by the app:

- accelerometer data, used only for tilt-based controls during gameplay
- device information, such as screen shape and screen size, used to adapt the interface and control behavior
- local storage on the watch, used to save game settings and recent scores

How the data is used:

- accelerometer input is read in real time only to control the ship
- device information is used to choose the correct layout and supported behavior for the current watch
- settings and score history are stored locally on the watch so the player can keep preferences and view previous results

Data sharing:

- the app does not send personal data, gameplay data, device data, scores, or settings to the developer
- the app does not upload data to cloud services
- the app does not share data with third parties

Data retention:

- settings and score history remain on the watch until the user clears app data or removes the app

User account and identity:

- the app does not require account registration
- the app does not use login, advertising identifiers, or social features

Third-party SDKs:

- the app does not include third-party SDKs in the released watch package
