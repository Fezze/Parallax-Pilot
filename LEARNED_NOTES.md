# Learned Notes

- Official Zepp Simulator supports `zeus dev`, Developer Bridge mode, and default address `http://127.0.0.1:7650`.
- Local simulator automation here uses Linux desktop tooling for input (`xdotool` or `ydotool`) and screenshots (`scrot`, `gnome-screenshot`, or `grim`).
- Sources:
  - https://docs.zepp.com/docs/guides/tools/simulator/
  - https://docs.zepp.com/docs/v2/guides/faq/developer-bridge-mode/
  - https://docs.zepp.com/docs/guides/tools/studio/
